# 아이콘 모듈 — 공개 후보

현재 공개 후보는 검색·미리보기·삽입과 태그·통합팩 연동을 포함합니다. 아래 문서는 과거 설계 기록입니다. 현재 설치·기능·미검증 범위는 [루트 README](../../../README.md), [빌드 문서](../../../docs/BUILD.md), [검증 기록](../../../docs/VALIDATION.md)를 우선 확인하세요.
# 루리웹 아이콘 Phase 1 테스트 빌드

기존 Aru Source Captioner 0.1.1에 독립적인 아이콘 기능을 추가한 테스트 소스입니다. Phase 1 판정은 **구현 반영 · 대상 브라우저 검증 대기**입니다. 스토어 배포본이나 서명된 Firefox XPI가 아닙니다.

확장 설정에서 기존 확장 기능과 `루리웹 아이콘 기능`을 모두 켜면 사용할 수 있습니다. 신규 아이콘 기능은 기본적으로 꺼져 있습니다. 기존 설정을 초기화하지 않습니다.

- 기본 아이콘 선택기에서 팩을 선택하면 확장 화면이 열립니다. `자동 추가 수집`을 켜면 사이트의 정상 추가 버튼을 순차적으로 사용합니다.
- 아이콘 게시판 98의 공개 글에서는 `확장 아이콘 보기 · 읽기 전용` 버튼으로 메타데이터를 읽습니다.
- 여러 검색어는 모두 일치해야 합니다. 각 검색어는 현재 그룹의 카테고리·별칭 또는 아이콘의 이름·태그·키워드 중 하나에 일치하면 됩니다. 태그 칩은 한 가지를 선택하며 검색어와 함께 적용합니다.
- 검색 중 접은 그룹은 검색어가 바뀌어도 접힘을 유지합니다. 검색 초기화 시 검색 전 접힘 상태를 복원합니다.
- 캐시 화면은 취득 시점의 자료입니다. `원본 다시 읽기`로 캐시를 무효화하고 재수집합니다. 오류·중지 후 `재시도`는 현재 사이트 목록에서 이어서 읽습니다.
- `기존 선택기`를 누르면 확장 화면과 수집 작업을 닫습니다. 사이트의 원래 선택기에서 계속 작업할 수 있습니다.

`선택 정보 준비`는 아이콘 URL과 네이티브 삽입 후보를 확인하는 인터페이스입니다. 실제 에디터 삽입·댓글 전송·게시글 작성·즐겨찾기 변경은 수행하지 않습니다. 403·401·429 같은 접근 거절은 우회하거나 자동으로 재시도하지 않습니다.

실제 Firefox·Whale에 설치한 상태에서의 출처 기입·EXIF·다운로드·Native Host 및 새 수집 기능은 검증 대기입니다. 상세 기록은 소스 묶음의 `phase1-artifacts/README.md`와 `TEST-RESULTS.md`에 있습니다.

## Phase 2A 개발 복사본

댓글·답글은 작성기별 네이티브 아이콘 버튼 옆의 아루 버튼으로 열며, 선택 후 확인 · 삽입에서만 app.select_icon을 호출한다. 기존 업로드 첨부는 자동 교체하지 않는다. 에디터2(Summernote)는 확인된 app.editor_insertContents API를 사용한다. 커서·실행 취소·직렬화 결과를 확인하고 실패 시 복원한다. 구 에디터·코드 보기는 지원 대기이다.

NORMAL/BUNDLE 판독·가상 목록·검색·캐시 및 이미지/MP4/WEBM 다운로더는 보존했다. 실제 Firefox·Whale 설치 실행 검증은 사용자 수동 검증 필요이다. Chromium 사이트 조사와 테스트 DOM 검증은 Firefox 확장 검증과 구분한다.

최신 개발 보고서와 실행 절차: phase2a-artifacts/REPORT.md 및 phase2a-artifacts/FIREFOX-MANUAL.md. 이 디렉터리의 이전 ZIP과 테스트 결과는 이전 버전 기록이다. 이번 테스트 패키지는 phase2a-artifacts/packages 아래에 있다.
