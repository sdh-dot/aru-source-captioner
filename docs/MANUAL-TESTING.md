# 브라우저 수동 검증

Chrome·Edge·Whale·Firefox는 각각 별도 테스트 프로필을 사용합니다. 기존 확장을 제거하거나 프로필·설정·로그인을 초기화하지 마세요. 실제 게시글·댓글 등록은 이 테스트에 필요하지 않습니다.

1. README대로 해당 폴더를 로드하고 Manifest/CSP/리소스 오류가 없는지 확인합니다.
2. 옵션의 기존 기본값과 신규 아이콘 기능 OFF 상태를 확인합니다.
3. 합성 파일명 `12345678_p0.png`의 자체 제작 이미지를 첨부해 픽시브 작품 URL이 연결되는지 확인합니다. 실제 타인 그림을 테스트 저장소에 넣지 않습니다.
4. 출처가 들어 있는 테스트 메타데이터 파일과 출처 없는 파일을 비교합니다. 이미지·작성 내용·기존 출처 캡션의 중복/손상이 없어야 합니다.
5. 아이콘 기능을 켜고 정상 공개 NORMAL/BUNDLE과 기본 즐겨찾기에서 검색·태그·미리보기·스크롤을 확인합니다.
6. 빈 댓글·답글과 임시 게시글 작성기에 단일 클릭 → 삽입, PC 더블클릭을 확인합니다. 대상 작성기·커서·기존 텍스트·실행 취소를 확인하되 등록 버튼은 누르지 않습니다.
7. 태그 편집의 고정 13개·자유 태그·이미지/MP4와 팩 새로고침을 확인합니다.
8. 통합팩의 제목 검색·다중 선택·본문 적용을 임시 작성기에서만 확인합니다.
9. 본문 이미지/MP4 다운로드를 테스트 폴더에 저장해 확장자·형식·출처를 확인합니다. Native Host가 없을 때 메타데이터 기록 실패가 전체 UI를 망가뜨리지 않는지 확인합니다.
10. 라이트/다크·기본/넓게/최대화·작은 화면·ESC/X·포커스 복원을 확인합니다.

브라우저·버전, 수행 항목, 결과, 최소 오류 코드만 기록합니다. 전체 Console 로그·인증·쿠키·작성 내용은 전달하지 않습니다. Android Firefox는 별도 모바일 검증이며 PC 통과를 모바일 지원 완료로 보고하지 않습니다.
