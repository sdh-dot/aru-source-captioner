사용자 확인: 태그가 표시되는 아이콘은 검색·필터가 정상이고, 태그가 없는 아이콘만 검색·필터도 실패한다. 따라서 필터 이벤트를 임의 교체하지 않았다. 원본 저장 속성, 정확 URL 매핑, 참조 조회 실패, 태그 디코딩, 캐시 상태를 구분해야 한다. IMG 97개+MP4 3개의 100개 태그, 한글 조합, 고정 태그 AND/OR, 자유 태그 쉼표, 일부 누락과 잘못된 인코딩은 합성 테스트에서 검증했다.

3867/5039/5044의 bbs/m 공개 조회는 웹 도구에서 접근할 수 없었고, 별도 무인증 HTTP 조회는 200을 반환했지만 모두 **게시판 목록**이었으며 게시글 본문이 없었다. 이를 성공한 본문 조회나 Android 실환경 증거로 사용하지 않았다. 읽기 전용 진단으로 실제 DOM과 원본 대조 상태를 추가 확인해야 한다.

## 로딩 화면과 상태 관리

기존 공개 에셋 `firefox/assets/icons/aru-main-64.png`, `whale/assets/icons/aru-main-64.png`를 재사용한다. Wine×Champagne 기하학 A 아이콘이며 캐릭터 이미지가 아니다. 권리가 확인되지 않아 공개본에서 제외한 캐릭터 원본은 다시 넣지 않았다. 새로운 캐릭터를 생성하거나 이미지 확대를 하지 않았다.

CSS의 작은 상하 움직임만 추가했고 `prefers-reduced-motion:reduce`에서는 정지한다. 상태는 live region, 처리량은 native progress 요소로 전달한다. 팩 선택 창에도 진행 안내와 중지 경로가 있으며 검색·닫기·취소를 가리지 않는다. grid 로딩 업데이트만으로 가상 카드를 재생성하지 않는다. 기존 카드 72개 한도와 미디어 동시 4개 제한을 유지한다.

팩 선택은 정상 데이터가 준비될 때만 commit한다. 실패하면 이전 팩을 유지한다. 다른 선택과 닫기는 AbortController와 generation 검사를 사용하며, 늦게 돌아온 결과를 새 목록에 반영하지 않는다. 기존 태그/즐겨찾기/설정의 전체 삭제나 초기화는 없다. 페이지의 원래 overflow 값을 마지막 모달 종료 때 복원한다.

이미 전송한 브라우저 캐시 IPC는 취소할 수 없어 cache/storage 단계의 중지 버튼은 비활성화한다. 닫기는 가능하지만 그 작업이 실제로 취소됐다고 표시하지 않으며 완료 응답의 화면 반영을 차단한다. native 사이트 목록 단계는 추가 수집을 중지하는 것으로 표시하고 사이트 자체가 이미 시작한 요청까지 취소한다고 주장하지 않는다. 공개 글 fetch에는 실제 AbortSignal을 전달한다.

## 성능 측정

`node tools/benchmark-mobile.mjs`. 기존 공개 커밋과 개발 소스 각각 워밍업 1회 후 5회 중앙값. Node/jsdom, 360px, 합성 1,548개 / 17개 참조. 네트워크와 미디어를 다운로드하지 않으며 참조 간격은 0ms로 지정한다. Windows 타이머/CPU 변동을 포함하므로 Android 체감 속도로 환산할 수 없다.

| 측정(ms) | 독립 원본 17개: 전 → 후 | 같은 원본 반복 17개: 전 → 후 |
|---|---:|---:|
| BUNDLE 메타데이터 해석 | 59.38 → 54.13 | 56.87 → 54.74 |
| 원본 URL·태그 대조 전체 | 732.48 → 657.88 | 692.65 → 47.31 |
| 위 대조에 포함된 원본 DOM 파싱 | 30.27 → 29.77 | 26.97 → 1.58 |
| 원본 1개의 URL·태그 수집 | 19.80 → 19.55 | 19.84 → 20.98 |
| 검색 색인·검색 | 31.85 → 30.67 | 17.67 → 17.85 |
| 가상 목록 초기 렌더 | 49.52 → 45.71 | 30.96 → 33.13 |
| 원본 조회 콜백 수 | 17 → 17 | 17 → 1 |

독립 원본 사례는 1,548개 모두 태그 연결·검색되고 실제 DOM은 12개 카드였다. 반복 원본 사례는 1,548개 참조 슬롯을 유지하되 같은 원본 식별자에 따른 선택기 중복 제거로 92개 검색 대상이 된다. 기존과 변경 후 결과가 같다. 반복 사례의 요청 수 감소는 확정적이며, 모든 통합팩이 그만큼 빨라진다고 주장하지 않는다. 이전 측정에서는 독립 원본 처리 시간이 증가한 실행도 있어, 작은 시간 차이는 일반적인 속도 보장으로 해석하지 않는다.

독립 17개 원본에는 기본 300ms×17 = 5.1초의 조회 간격도 존재한다. 실제 서버 측정 없이 이 간격을 줄이거나 동시 요청을 늘리지 않았다. 브라우저 저장소 통신, 실제 HTTP 시간, 미디어 다운로드/디코딩, Android CPU/메모리/프레임은 **미측정**이다. 실제 병목 확정 및 추가 최적화에는 기기 측정이 필요하다.

역사적 테스트 96건과 Mozilla 경고 9건 기록은 삭제하지 않았다. 개발 트리의 네 건 차이는 주변에 이전 버전 파일이 존재하는 경로 차이이며 이번 기능 수정으로 네 결함이 해결됐다는 뜻이 아니다. 원래 테스트와 기대값을 바꾸거나 실패를 숨기지 않았다. 이전 전체 RC3 테스트 707개를 이번에 재실행한 것은 아니다.

IAB Console에서 `MutationObserver.observe`의 Node 형식 오류 1건이 관측됐다. 발생 소스는 미확정이며 최종 재로드에서 추가 발생은 관측하지 않았다. 이를 제품 문제 또는 도구 문제로 단정하지 않는다. 로컬 UI의 CSP 오류는 관측하지 못했으나 설치된 확장의 CSP·브라우저별 미디어/브리지 검증 완료로 해석하지 않는다.
