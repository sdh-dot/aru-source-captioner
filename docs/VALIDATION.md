공개 후보 테스트는 검색 엔진, URL·BUNDLE 규격, 검색 응답 파싱·일괄 선택, 메타데이터, 공개 파일 조건을 검사합니다. 기능 전체의 실환경 검증을 대체하지 않습니다. 원문 역사적 테스트를 삭제하거나 기대값을 변경하지 않았습니다.

## 기존 테스트와 미해결 항목

원문 테스트는 `docs/tests/`에 보존했고 `npm run test:historical`로 별도 실행합니다. 이번 단독 트리의 실행 결과는 **287개: 191 통과 / 96 실패 / 건너뜀 0**입니다. 이전 버전·제외한 ZIP·옛 에셋/화면 비교·미포함 진단 자료를 요구하는 실패와 이전 UI 정책 가정을 포함합니다. 이를 전부 기능 정상으로 간주하거나 성공으로 재분류하지 않습니다. 상세 실패 원문은 로컬 공개 준비 감사 자료에 보존하며 개인정보·로컬 경로가 있어 public Git에 올리지 않습니다.

기존 RC3에서 보관한 전체 결과는 707개 중 663 통과 / 44 실패입니다. 이는 이전 작업 시점의 결과이며 이번에 그 707개를 다시 실행해 통과했다고 주장하지 않습니다. 새 공개 후보 59개만 통과한 것으로 구분합니다.

Mozilla 경고 9건은 메타데이터·통합팩 UI/브리지의 동적 `innerHTML` 대입 관련입니다. 이번 공개 작업에서 기능 코드를 임의로 변경하지 않았습니다. 일반 lint는 경고를 출력하고, strict 명령은 실패합니다. 공개 CI는 일반 lint를 실행하므로 오류를 차단하고 경고는 로그에 남깁니다. 추후 보안 리뷰와 스토어 심사에서 확인해야 합니다.

기존 Firefox exifr의 선택적 의존성 로더 수정이 확인됐으며 이를 재현하는 스크립트와 라이선스·해시를 제공합니다. 수정 라이브러리의 Mozilla 심사 적합성은 미확인입니다. 기존 제출 패키지와 공개 플레이스홀더 패키지는 그래픽이 다르므로 같은 산출물로 설명하지 않습니다.

초기 실행에서는 제외 자료 2개·결과 폴더 1개가 없어 실패했고 새 테스트 1개가 기존 태그 디코더 반환값을 잘못 취급했습니다. 합성 BUNDLE 자료·최소 공개 검색 사실·결과 폴더 생성·새 테스트 호출을 보완했습니다. 원문 테스트의 기대값이나 제품 디코더는 바꾸지 않았습니다. Git index 줄바꿈으로 vendor hash가 달라진 문제는 두 vendored JS에 byte 보존 속성을 적용해 해결했습니다.

## 화면 확인 범위

연결 브라우저 목록은 Codex IAB와 MCP Apps만 반환했습니다. 설치된 Chrome/Edge/Whale/Firefox 확장은 조작하지 않았습니다. IAB의 로컬 페이지에서 공개 후보의 실제 선택기 코드를 렌더링해 직접 만든 PNG 100개·검색 `미소` 50개·카드 선택·미리보기·삽입 콜백을 확인했습니다. 이것은 실제 루리웹 작성기 삽입이나 확장 설치 검증이 아닙니다.

README 화면은 이 로컬 렌더링입니다. 테스트 페이지의 localhost 미디어 허용과 작성기 콜백은 demo에만 있으며 확장에 포함되지 않습니다. 실제 설치·Native Host·루리웹 작성기·모바일·터치는 [수동 절차](MANUAL-TESTING.md)가 필요합니다. 사용자 프로필·로그인·작성 내용·설치본과 원본 소스는 변경하지 않았습니다.
