# 캐릭터 에셋 고지

프로젝트 소유자는 2026-10-15 대화에서 기존 아루 캐릭터 PNG의 공개 재배포
권한이 확인됐다고 명시했다. 이에 기존 Design Polish RC3의 개별 PNG를
새 개발 브랜치의 Firefox·Whale에 동일하게 적용했다.

이 확인은 캐릭터 에셋에 프로젝트의 MIT 라이선스를 적용하거나 저작권을
프로젝트로 이전한다는 뜻이 아니다. 소스 코드의 MIT와 그래픽 권리를 구분한다.
별도의 에셋 재사용·변형·상업 이용 허락을 이 저장소가 부여하지 않는다.
필요한 이용 권한과 고지 사항은 해당 권리자 또는 제공자에게 확인해야 한다.

새 캐릭터를 생성하거나 원본 시트·설명 패널을 패키지에 넣지 않았다.
이미지 첨부 버튼에는 기존 사진 프레임 캐릭터 PNG를 `editor-upload-*`라는
이름으로 재사용했다. 전용 업로드 캐릭터 원본이 별도로 제공된 것으로
표현하지 않는다. 원본 비율·투명 배경과 픽셀 크기를 유지했다.

기존 파일의 출처 구분과 SHA-256은 `CHARACTER-ASSET-PROVENANCE.json`에 기록한다.
