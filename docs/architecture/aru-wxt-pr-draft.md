# 2026.10.16 - PR #4·#5 통합 및 WXT 기반 구조 개편

이 문서는 사용자 검토용 초안이다. GitHub에 등록하지 않았다. 예정 Base는 `main`, Head는 `integration/aru-wxt`이며, 공개·병합은 별도 검토 후 진행한다.

## 변경 목적

PR #4의 최신 기능과 PR #5의 WXT 구조를 별도 브랜치에서 통합하고, 제품 원본을 TypeScript 중심으로 관리하기 위한 변경입니다. 기존 PR과 외부 포크는 수정하거나 자동 병합하지 않았습니다.

## 주요 내용

- PR #4 `183784c`의 NORMAL 태그 수정·Hybrid 검색/인덱스·DOM 감시·파싱 큐 개선을 유지했습니다.
- PR #5 `a817704`의 WXT·브라우저별 entrypoint·Manifest 생성·oxfmt/oxlint 구성을 검토해 적용했습니다. 오래된 IIFE·예제 템플릿·개인 브라우저 설정은 제외했습니다.
- 제품 원본과 모델 58개 파일을 TypeScript로 관리하며 WXT에서 직접 import합니다. 관리 원본 IIFE는 0개입니다.
- 공통 PNG 파서와 Picker 종료 책임을 분리했습니다. 기존 태그·메타데이터·저장 키·ID·이벤트·브라우저 권한 계약을 유지했습니다.
- 기존 ESM/classic 호환 경로는 TypeScript에서 자동 생성합니다. 현재 테스트·배포 호환에 필요한 Compat는 보존했습니다.
- 정리 브랜치 `282ff66`의 분류 결과와 필요한 ignore 규칙을 재사용하고, 참조가 없는 내부 코드·주석·원본 안내를 정리했습니다.

## 검증 결과

- 타입·oxfmt·oxlint 통과. ESM 51개·통합 계약 4개·TypeScript 직접 검증 8개·회귀 111개·RC3 59개 통과.
- Historical 193개 통과·기존 94개 실패, 새 실패 이름 없음. Firefox classic Lint 오류 0·기존 경고 9.
- Firefox·Chromium·Whale WXT 빌드, Manifest/권한/World/리소스 비교, TS·ESM·classic 생성 일치 검사 통과.
- 세 브라우저에서 실제 확장 로드·옵션 저장과 합성 페이지의 검색·필터·삽입·MAIN 태그 편집/직렬화를 확인했습니다. 공개 사이트는 읽기 전용으로 확인했습니다.
- AST 비교는 중괄호 스타일만 정규화하고 조건·순서·선언을 계속 비교합니다. 팔레트 검사는 기존 색상과 `Object.freeze` 초기화 전체를 비교하도록 출력 포맷 의존성만 제거했습니다. 동결 데이터·Fixture는 유지했습니다.

## 미검증 사항

실제 로그인 작성기 게시·업로드, Android 기기, Native Host, 장시간 MV3 종료/재시작과 서명·스토어 심사는 미검증입니다. 공개 본문에 태그가 없는 경우와 옛 스크립트 파일명 검사 등은 BLOCKED로 기록했습니다. 중간 Firefox의 공개 탐색 시간 초과 1회와 자동화 중 요소 교체 오류 1회는 같은 코드 재실행에서 해소됐으며 실패 기록도 보존했습니다. 자동화의 간헐 오류 안정화는 후속 과제입니다.

사이트·브라우저·기존 resolver의 동적 API 타입이 남아 있습니다. 전체 Picker 재작성이나 모든 호환 계층 제거를 완료했다고 주장하지 않습니다. 외부 개발자의 이후 미공개 WXT 변경도 포함하지 않습니다.

명시적 Firefox ID와 기존 Manifest 필드는 보존했습니다. Chromium/Whale unpacked 개발 ID는 로드 경로에 따라 달라질 수 있으며 기존 서명 설치의 ID·저장 데이터 업그레이드는 미검증입니다. 새 프로필 검증에서 개인 프로필을 사용하거나 데이터를 이전하지 않았습니다.
