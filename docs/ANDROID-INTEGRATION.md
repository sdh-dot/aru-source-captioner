## 후속 수정

NORMAL 팩의 태그 디코딩 실패가 있으면 미디어를 버리지 않고 상태를 partial로 유지한다. 캐시와 전체 팩 검색에서도 이 상태를 보존하여 다음 수집에서 다시 확인한다. 태그가 없는 정상 자료를 오류로 바꾸거나 태그를 추정하지 않는다. 성공적으로 다시 읽으면 complete가 된다.

추가 회귀 5개는 NORMAL 완료 상태·오류 캐시·전체 팩 재시도, 3867의 동일 글 식별자와 정확한 미디어 URL 매칭, 리다이렉트/본문 없는 응답 거부를 다룬다. 수정 전 NORMAL 관련 3개 테스트가 실패하는 것을 확인했다. 저장 구조/마이그레이션·즐겨찾기·삽입 브리지·코덱·Manifest 권한은 변경하지 않았다.

## 역사적 테스트 차이

ZIP 문서는 이전 작업 환경에서 195 통과/92 실패를 보고했지만, 이전 버전 자료가 주변 폴더에 존재해 생긴 차이라고 명시한다. 이번 별도 clone은 main과 동일하게 191/96이다. 누락된 이전 버전·에셋·진단 자료와 오래된 UI 가정에 의존한다. main 로그와 실패 이름 96개를 대조하여 새 실패·제거된 실패가 모두 0개임을 확인했다. 이 실패들을 이번 개선으로 해결했다고 표시하지 않는다. CI의 공개 후보 테스트와 역사적 suite는 별도이며, CI 성공이 모든 역사적 테스트 성공을 의미하지 않는다.

## 3867 조사와 보류

PC/mobile origin은 동일한 `/community/board/98/read/3867` 식별자로 구성한다. 응답 리다이렉트/다른 최종 URL은 거부하고 정확한 원본 미디어 URL만 대조한다. 경로나 쿼리를 추측 변경하여 일치시켜서는 안 된다. 최대 5개의 누락 위치/공개 CDN 경로를 진단에 제공하며 쿼리는 진단 출력에서만 생략한다.

이번 무인증 PC/mobile HTTP 조회는 200이었지만 대상 게시글 본문을 확보하지 못했다. 실제 5044의 3867 참조 URL과 원본 DOM을 대조할 근거가 없으므로 원인은 미확정이다. HTTP 200만으로 수집 성공으로 판정하지 않는다. [수동 체크리스트](MOBILE-MANUAL-TESTING.md)와 [미해결 항목](KNOWN-ISSUES.md)을 따른다.

공개 회귀는 검색/필터·한글·태그·GIF/WEBP/MP4 관련 데이터·중복 요청/취소·작은 화면 모델을 검증한다. 기존 댓글/답글/Summernote 삽입 및 저장/마이그레이션 구현은 보존했지만 모든 실제 브라우저 기능을 자동 테스트만으로 보증할 수 없다. Firefox 데스크톱·Whale과 Android에서 체크리스트를 각각 실행하고 결과를 기록한 뒤 Draft PR의 병합 여부를 판단한다. 이 작업에서 merge·스토어 제출·release는 수행하지 않는다.
